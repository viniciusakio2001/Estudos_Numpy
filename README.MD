# Estudos de NumPy

Projeto de estudos de NumPy do nível iniciante ao avançado.

O objetivo é aprender manipulação de arrays, operações vetorizadas, estatística, álgebra linear, otimização de memória e aplicações em análise de dados e Machine Learning.

## Objetivos

- Aprender os fundamentos do NumPy.
- Entender arrays multidimensionais.
- Trabalhar com indexação, filtros e máscaras.
- Utilizar operações vetorizadas.
- Compreender broadcasting.
- Aplicar funções estatísticas.
- Trabalhar com álgebra linear.
- Otimizar desempenho e uso de memória.
- Desenvolver projetos práticos com dados.
